# Ciel

Instaladores de **Ciel**: optimización interna de Windows medible y reversible.

## Instalar

1. Entrá a [la última versión](https://github.com/Lev1tao/ciel-release/releases/latest) y descargá `Ciel_X.Y.Z_x64_es-ES.msi`.
2. Abrilo y seguí el asistente. Windows pide permiso de administrador porque Ciel instala un servicio.

Requisitos: Windows 10 22H2 u 11, de 64 bits.

## Actualizaciones

Una vez instalado, Ciel busca versiones nuevas por su cuenta y te avisa antes de instalarlas. Cada versión viene firmada y la app rechaza las que no tienen la firma correcta.

Windows SmartScreen puede avisar de un «editor desconocido»: el instalador no tiene un certificado comercial de firma de código.
